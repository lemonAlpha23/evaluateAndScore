# 局域网语音真实性盲评

听众在手机或电脑浏览器中播放匿名样本，分别为音色接近真人、语调和重音、语速和停顿、语气和表现力、咬字和内容清晰度打 1–5 分。每段录音的真实性得分取五项的算术平均值，满分 5 分。

## 启动

在项目根目录运行，保持终端开启。服务只使用 Python 标准库。

```powershell
uv run --no-project src/evaluateandscore/server.py
```

双击 `启动盲评.bat`，浏览器会使用本机的局域网 IPv4 地址打开答题首页。连接同一局域网的参与者可直接使用启动窗口中显示的同一地址。若需指定网卡，可用 `ipconfig` 查看地址，再运行 `.\启动盲评.bat --host 192.168.1.70`，将示例 IP 换成该网卡的实际地址。如果本机能打开而其他设备无法连接，请检查 Windows 防火墙是否允许专用网络访问该 TCP 端口。

默认监听 `0.0.0.0:8765`，每题 2 段，每轮题数根据当前待评录音数量自动确定。也可以在启动时指定每轮 10 题、每题 3 段。

```powershell
uv run --no-project src/evaluateandscore/server.py --questions 10 --samples-per-question 3 --port 8765
```

已安装项目时，也可以使用命令 `evaluateandscore`，参数相同。

## 音频与抽题

| 目录（相对于项目根目录） | 用途 |
| --- | --- |
| `src/evaluateandscore/datasets/raw/` | 同一说话人的真人原始录音 |
| `src/evaluateandscore/datasets/test/` | 该说话人的语音克隆录音 |
| `src/evaluateandscore/result/` | 服务端生成的正式答卷 |

将文件直接放入相应目录。每次开始新一轮时重新读取目录。支持 WAV、MP3、M4A、OGG、FLAC、WebM，具体播放能力取决于参与者的浏览器。当前数据所用的 PCM WAV 可以直接使用。

- 每轮从 `datasets/raw/` 随机选一段真人原声，仅用于回听对照。所有待评样本都从 `datasets/test/` 抽取，以编号展示。
- 自动出题时，若所有录音能放进一题，就只出一题。否则，题数等于待评录音数，每段出现的次数相同，每题的素材组合都不同。按默认设置，6 段录音生成 6 题，每段会与另外两段录音各搭配一次。题目顺序和题内播放顺序每轮都会打乱。
- 指定 `--questions` 时，按指定题数出题，优先抽取本轮出现次数较少的录音。同一题内每段录音最多出现一次。
- 可在当前浏览器标签页刷新并继续答题。未提交的轮次有效期为 24 小时，重启服务后需要重新抽题。

## JSON 结果

每次完成后生成 `result/<答题轮次 ID>.json`。服务端使用直接连接的 IP 作为 `participant_ip`。同一 IP 重新答题会获得新的 `attempt_id`，同一轮重复提交只保留一份答卷。

每份 JSON 包含开始和提交时间（UTC）、参考音文件名（`reference_file`）、量表和中文维度名称。`questions[].samples[]` 按听众看到的题目和样本顺序保存克隆录音的相对路径、来源 `clone`、五项原始评分 `scores` 及其平均值 `authenticity_mean`。

每个样本的 `feedback` 保存听众为该次试听填写的文字反馈，支持多行。未填写时保存为空字符串。

IP 标识的是网络地址。共用一台设备或经同一代理访问时，多名听众可能共用同一标识。需要逐设备记录 IP 时，请让参与者直接访问局域网服务地址。
